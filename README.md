# Survey Feedback Analyzer
A python project for cleaning and analyzing survey feedback to extract meaningful insights.
## Key Features
- Collect and store survey feedback
- Clean and standardize text data
- Count specific words in feedback
- Calculate average ratings
- Identify the longest feedback comment
- Extract unique words from feedback
- Generate summary insights
## Concepts Used
- Lists and Dictionaries
- Loops and Conditional Statements
- String Operations
- User-Defined Functions
- List Operations
